# Portafolio Profesional - Erin Mauricio

Bienvenido a mi portafolio personal. Este proyecto es una vitrina de mi trayectoria como estudiante de **Análisis y Desarrollo de Software (ADSO)**, donde combino mi pasión por la lógica de programación con un diseño moderno y minimalista.

## Sobre el Proyecto
El portafolio ha sido diseñado desde cero buscando una estética **"Modern Floating"**, utilizando una estructura asimétrica y efectos de transparencia (Glassmorphism) para ofrecer una experiencia de usuario fluida y profesional.

### Tecnologías Utilizadas
* **HTML5:** Estructura semántica y moderna.
* **CSS3:** Diseño original con Grid, Flexbox y animaciones de scroll.
* **Google Fonts:** Tipografía "Space Grotesk" para un aire tecnológico.
